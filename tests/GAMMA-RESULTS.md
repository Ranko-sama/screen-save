# 双模式版本验证记录

日期：2026-10-06。本机：Xiaomi Book Pro 14 / Windows 11 / Intel Arc B390。

本文件记录新版本；`RESULTS.md` 是此前单一颜色矩阵版本的历史数据，不能把两次不同背景负载的 GPU 数字直接比较。

## 已完成的功能验证

- Gamma 线性输出系数 1.0–0.5 可写入并完整读回，0.45 及以下的探测设置返回失败；不宣称 Gamma 能全黑。
- 新版本的全部 20 档（每档系数下降 0.025）均可准确写入和读回；恢复原表逐字节一致。
- 用户目视确认 Gamma 测试“明显变暗，最后恢复正常”。
- 使用真实 Ctrl+Alt+B 快捷键进入 Gamma 最暗档：颜色矩阵系数保持 1，Gamma 白点由 65535 变为 32767；再按后恢复原表。
- 原生测试窗口在 Gamma 最暗档成功输入 `GAMMA INPUT OK` 并点击确认，截图仍显示正常色块。
- 浏览器测试页的静态色块截图，正常与 Gamma 最暗时均为 4551 bytes，逐字节完全一致；输入 `GAMMA BROWSER INPUT OK` 后点击成功。
- 第 20 档 Gamma → 矩阵：Gamma 恢复 65535，矩阵系数变为 0；矩阵 → Gamma：矩阵恢复 1，Gamma 变为 32767。两个效果不叠加。
- 从 Gamma 最暗状态通过正常 WM_CLOSE 退出，进程退出码为 0，矩阵与 Gamma 均恢复，保活标志释放。
- 补测全部 20 档、最低档继续降低、从第 7 档切到最暗后恢复第 7 档、逐档调亮至原表；Gamma 恢复前硬件保持 0，下一次调亮后硬件变为 5。测试结束恢复硬件亮度 100。
- 持续测试后，通过 Windows computer-use 实际发送 Ctrl+Alt+PageDown / PageUp：硬件 0 时降低得到 Gamma 白点 63896（第 1 档）；提高后 Gamma 白点恢复 65535、硬件仍为 0；再提高后硬件变为 5。程序正常存活，未出现同步消息诊断中的错误。

模式切换使用正式程序的 WM_COMMAND 菜单处理入口进行集成验证；关闭使用正常窗口关闭路径。未把消息级验证描述为实际鼠标点击系统托盘的验证。

十二轮均无页面隐藏或失焦事件，结束时可见且有焦点。所测五项浏览器指标的三轮中位数，Gamma 相对正常最大变化约 +0.40%，矩阵约 +1.96%，均在 ±5% 内；这不等于所有工作负载均有相同性能。

程序 CPU 的 0 来自 Windows 进程 CPU 时间计数的测量精度，不表示物理上的绝对零消耗。本机 16 个逻辑处理器，表中 CPU 按单个逻辑处理器为 100% 计算。内存分别为进程 PrivateMemorySize64 和 WorkingSet64；DWM 列为性能计数器 Working Set - Private，二者口径不同。

Gamma 的 DWM GPU 与未运行差值约 **+0.00030 个百分点**，处于本次背景波动量级；三轮 Gamma 为 0–0.00244%，未运行为 0.00084–0.00332%。因此本次没有测出明显的 Gamma 持续 GPU 负担。矩阵三轮均为 3.99–4.05%，明显高于同次基线。

DWM 服务整个桌面，GPU 列是其各引擎计数器之和，不是整机 GPU 总百分比。DWM CPU 背景波动明显：未运行 1.22–4.54%，未压暗 0.66–4.86%，Gamma 1.33–8.06%，矩阵 12.71–13.17%。不能把全部差值归因于程序，也不能证明 DWM CPU 严格落在 ±5% 内。矩阵模式仍不能宣称满足整体资源开销 ±5% 的要求。

## 持续测试

正式 EXE 在 Gamma 第 20 档完成 **900 秒**前台渲染测试：FPS 119.999991，帧间隔 P95 8.5 ms，最长帧间隔 9.7 ms，定时器间隔 P95 24.9 ms，固定计算耗时中位数 4.7 ms、P95 5.2 ms。hidden_events=0、blur_events=0，结束时 visible、has_focus=true。未观察到渲染暂停。

独立电源监测持续 **960.016 秒**：显示状态始终 On，non_on_events=0、suspend_events=0，结束时距最后一次系统输入 1179.469 秒。监测程序自身不申请保活，短时资源对照工具此时已退出。

程序资源观测窗口 **976.653 秒**，CPU 时间增量为 0、平均 CPU 0.000%；结束时私有内存 3,006,464 bytes（2.87 MiB），工作集 17,334,272 bytes（16.53 MiB）。Gamma 白点仍为 32767，矩阵系数仍为 1，保活标志仍为 3。

最后再次进入 Gamma 最暗并通过正常 WM_CLOSE 退出：退出码 0，Gamma 白点恢复 65535、矩阵系数 1、保活标志 0。硬件亮度恢复测试前的 100。随后重新启动正式程序，处于默认矩阵模式、未压暗状态；临时测试页、原生测试窗口和本地测试服务已关闭。

读取的当前电源计划为交流电源从不息屏、交流与直流均从不自动睡眠，直流息屏为 180 秒。因此本轮只能验证持续显示/渲染及保活请求设置与释放，不能宣称覆盖了原本会发生的交流电源息屏/睡眠倒计时。没有修改电源计划。

## 测试工具异常与修正

性能十二轮完成后，最初的边界测试以跨进程同步 `SendMessage(WM_HOTKEY)` 注入事件。该上下文禁止出站 COM 调用，亮度查询失败后程序异常退出；该次边界记录 `gamma-boundary.txt` 无效，不计入通过结果。

用独立诊断程序复现：直接 WMI 查询返回 `0x00000000`，跨线程同步消息中返回 `0x8001010D`（RPC_E_CANTCALLOUT_ININPUTSYNCCALL），排队消息中返回 `0x00000000`。测试工具改为与真实热键一致的 `PostMessage`，并在正式程序未运行时直接报告测试失败。随后完整边界复测通过。正式程序未因此添加兼容层或重试，也未修改 EXE，先前十二轮性能结果仍适用。
