# Screen Save

为当前 Xiaomi Book Pro 14 编译的离线亮度调节程序。运行 `dist/ScreenSave.exe`，仅显示一个托盘图标。

| 操作 | 快捷键 |
| --- | --- |
| 降低亮度 | Ctrl+Alt+PageDown |
| 提高亮度 | Ctrl+Alt+PageUp |
| 最暗／恢复进入前的状态 | Ctrl+Alt+B |

正常范围每次调整系统亮度 5 个百分点；系统亮度到 0 后，再次降低才进入额外压暗，共 20 档。调亮时先撤销额外压暗，再提高系统亮度。

本版采用已确认的备用组合键，未接入原生 Fn 亮度键；原生按键仍由系统处理。

托盘菜单包含“黑屏／最暗／恢复”“调光方式”和“退出”。在“调光方式”中选择：

- **颜色矩阵（可全黑）**：默认模式，保留原有实现。
- **Gamma（不能全黑）**：使用本机有效的 Gamma 输出系数 1.0–0.5，均分为 20 档。这里的系数是 RGB 查找表的缩放比例，不是实体屏幕亮度百分比；本机拒绝更低的线性系数。

两种方式共用档位、快捷键和保活逻辑，不创建遮罩窗口。切换时先恢复旧方式，再按当前档位应用新方式；两种效果不叠加。Ctrl+Alt+B 切换当前方式的最暗档，再按恢复此前档位。选择仅本次运行有效，下次启动仍为颜色矩阵。

压暗期间阻止自动息屏和睡眠，恢复正常颜色后释放保活请求。通过“退出”结束时恢复程序修改的原始颜色矩阵或 Gamma 表。

程序不联网，没有配置文件、日志、设置界面或自动启动。只需分发 `dist/ScreenSave.exe`；`tests/`、`build/` 和本地测试页面属于开发工具。

## 编译

使用本机 Visual Studio 2022 Build Tools 和 Windows SDK，在项目目录运行 `build.cmd`。生成的 EXE 静态链接 C++ 运行库。
